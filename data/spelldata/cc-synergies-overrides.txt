# Synergies tab curation — dr_category / chain_target / is_peel / is_interrupt / pvp_duration_seconds.
#
# WHY THIS FILE EXISTS: every one of these five columns is manual_knowledge-tier, hand-curated
# by the domain expert (or bulk-applied from dr-categories-reference.md and individually
# verified) — none of it is derivable from the raw SimC/Game-Data-API dumps, and this project
# has repeatedly proven that trying to derive it is exactly the "AI invents a fact and presents
# it as ground truth" failure mode that keeps having to be caught and reverted (Mind Sear,
# alwaysAvailableAbilityIds(), spells.mechanic disagreeing with real dr_category on 2 of 4
# spot-checks — see CLAUDE.md's "Synergies tab" and "chain_target rule articulated" sections for
# the full history). Found missing 2026-08-11 the same way the baseline-spec-overrides.txt gap
# was originally found: a real deploy (migrate + import:spelldata on production) produced an
# empty Synergies tab, because every one of these five columns had only ever been written
# directly to the local dev DB via one-off scripts during the session that built the feature —
# never captured into a version-controlled file. This file is that capture, generated once by
# dumping the dev DB's full curated state, and is now the SOURCE OF TRUTH going forward — any
# future dr_category/chain_target/is_peel/is_interrupt/pvp_duration_seconds change must be added
# here, not just written to a local DB, or it will silently vanish on the next fresh import
# anywhere else (exactly the failure this file exists to prevent from recurring).
#
# Format: spell_id | dr_category | chain_target | is_peel | is_interrupt | pvp_duration_seconds | name (comment only, not parsed)
#   - dr_category: Stun | Disorient | Incapacitate | Root | Silence | Knockback | Disarm | Slow, or blank
#   - chain_target: healer | kill_target | both, or blank. STANDING RULE (see
#     CcChainBuilder's class docblock): kill_target/both may ONLY ever be used with
#     dr_category = Stun or Silence (CC that doesn't break on damage) — everything else
#     (Incapacitate/Disorient/Root/Knockback/Disarm/Slow) can only ever be healer or blank.
#   - is_peel / is_interrupt: "1" or blank.
#   - pvp_duration_seconds: a decimal (e.g. "6.0"), or blank. Real, per-spell confirmed PvP
#     duration — NEVER derived from spells.duration_seconds (confirmed unreliable/PvE-scoped
#     dataset-wide, see CLAUDE.md's "PvP CC duration cap" section).
#
# Matched by spell_id only (not class/spec) — these are properties of the spell/ability itself,
# not of who has it. Applied via a plain UPDATE against an existing spells row for the current
# patch; a spell_id not present in the current patch's data is skipped and warned about, never
# guessed at or auto-created.
#
# Adding or changing a line here is a real claim about the live game, not a data-cleanup nit —
# verify it (in-game, real player experience, or a source cross-checked with the domain expert)
# before adding, same discipline as baseline-spec-overrides.txt.
