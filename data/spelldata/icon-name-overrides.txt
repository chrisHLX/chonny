# Hand-curated icon-filename overrides for spells that are 100% real, player-visible abilities
# but are NOT queryable through Blizzard's public Game Data API at all — confirmed 2026-08-24 by
# directly checking both /data/wow/spell/{id} (404) and /data/wow/search/spell?name.en_US=...
# (zero exact-name matches anywhere in the index) for a sample of these. This is a different,
# deeper gap than the sibling-recovery fetch-spell-icons.php already does for spells whose
# *specific copy* lacks an icon while a same-named sibling has one — here, NO copy of the spell
# is indexed by Blizzard's public API under any spell_id, so there's no sibling to fall back to.
#
# These spells come from SimC's community datamine, which reads Blizzard's raw internal game
# files directly — a deeper source than the public REST API exposes. The spells are completely
# real and have real in-game icons; the icons just aren't reachable via spell-ID lookup.
#
# Each entry here was found by looking the spell up on Wowhead (a well-known, stable community
# database) and reading its "Icon:" quick-fact filename directly off the page — never guessed or
# derived. The actual FILE is still fetched from Blizzard's own official static icon CDN
# (https://render.worldofwarcraft.com/us/icons/56/{filename}.jpg — the exact same host Blizzard's
# own API returns URLs from, confirmed live 200 OK for every entry before being added here), so
# this doesn't introduce a new, un-vetted image source — it only changes how we learn the
# filename when Blizzard's own API can't tell us.
#
# Format: spell_id | icon_filename (no extension, no size prefix) | name (comment only)
#
# Applied to every same-named sibling spell_id in the current patch, not just the one listed
# here (see the "same visible ability split across several spell_id records" pattern documented
# throughout CLAUDE.md) — any of those copies could be the one a display path actually surfaces.
# Verify each entry the same way before adding: confirm on Wowhead, confirm the CDN URL resolves
# with a real 200, never bulk-guess a filename from a spell's name.
