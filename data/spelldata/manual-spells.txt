# Hand-authored spells missing from SimulationCraft's own raw dump entirely — confirmed absent
# at the source (not our own fetch/filter pipeline dropping them), so there is no spell record
# for the importer to annotate the way baseline-spec-overrides.txt annotates an existing one.
# SimC has no reason to track a spell with zero combat-simulation relevance (pure incapacitate,
# no damage/healing/resource component) — Polymorph is the confirmed case that started this file
# (2026-08-08); Hex is NOT one of these (it exists in SimC's dump as "Hex (desc=Frog)", excluded
# by the unrelated `(desc=...)` display filter — a different, smaller fix, not a manual-spells
# case). Repentance is correctly absent right now (pruned from the live game this patch) — do
# not add it here.
#
# Scatter Shot IS real and current, but it's a manual-spells.txt false alarm from an earlier
# check that only looked at the SimC dump and the Blizzard talent-tree JSON — neither is its
# real source. It returned in 12.1 as a PvP talent (real spell_id 213691, all 3 Hunter specs),
# sourced from data/pvptalents/hunter.json (Blizzard's Game Data API via fetch-talent-trees.php,
# not SimC at all) — confirmed 2026-08-13 already correctly imported with 3 valid
# spell_class_availability rows (source=pvp_talent). Never add PvP-talent-only abilities here;
# check data/pvptalents/{class}.json and pvp_talents/spell_class_availability in the DB before
# assuming a "missing from SimC" spell needs manual-spells.txt — some are simply sourced
# elsewhere. cooldown_seconds/mechanic are still genuinely blank for it (PvP talent JSON doesn't
# carry that data), a separate, smaller display gap — not an availability gap.
#
# Lives outside data/spelldata/filtered/{class}/ on purpose: regenerate-filtered.php /
# split-by-tree.php only ever overwrite specific known filenames inside those directories and
# never wipe them, so a file placed there would technically survive too — but authoring here
# means never having to hand-write SimC's own block syntax, which these scripts control and
# this file has no reason to imitate.
#
# Read by ImportSpellData::importManualSpells(), which creates the `spells` row directly AND
# writes spell_class_availability rows with source='verified_override' immediately (skipping
# the ambiguous baseline/spec_id=NULL step entirely) — unlike an imported SimC record, there is
# no ambiguity to record here: we already know the true spec ownership because we're asserting
# it, not inferring it from incomplete source data.
#
# Format: one block per spell, BEGIN/END delimited, `key: value` lines. Required keys: spell_id
# (the real Blizzard spell id — check it against a real tooltip/addon before adding, same
# verify-first discipline as every other file in this folder), name, class (class slug), specs
# (comma-separated spec slugs, or the literal word "all" for every spec of that class).
# Optional: school, description (write real numbers directly — no $d/$sN template tokens, since
# nothing re-resolves this text), cooldown_seconds, duration_seconds, charges, mechanic (must
# match a key in ModuleSpellReferenceService::MECHANIC_CATEGORY_MAP to categorize correctly),
# spell_type (Melee | Magic | Ranged | None — added 2026-08-23, same field SimC's own dumps
# carry for every other spell; a manual entry has no raw dump to read it from, so state it from
# real game knowledge the same way duration_seconds/cooldown_seconds already are), range_yards
# (free-text, e.g. "5 yards" — optional, spell_type alone is what wow:cc-formula's melee/ranged
# rule actually uses).

BEGIN
spell_id: 118
name: Polymorph
class: mage
specs: all
school: Arcane
mechanic: Polymorph
duration_seconds: 60
description: Transforms the enemy into a sheep, incapacitating them for 60 sec. Damage may interrupt the effect. Limit 1.
END

# cast by a real Subtlety Rogue) showing as an unresolved spell_id, same "absent from SimC
# entirely" shape as everything else in this file. Confirmed three ways before adding: (1) the
# raw combat log itself names it "Shadowstep" at every cast (a first-party source — the actual
# WoW client's own combat log), (2) a real spellbook_snapshot (id=6, Assassination Rogue)
# has spell_id 36554 with resolved_description confirming the name and the Thrill Seeking
# charge-grant relationship, (3) user-supplied Wowhead spell details: cooldown 30s, duration
# 3s, 10 Energy, 25 yd range, instant cast. Duration note: the spellbook snapshot's own
# resolved text says "2 sec" for the movement-speed buff, Wowhead's structured Duration field
