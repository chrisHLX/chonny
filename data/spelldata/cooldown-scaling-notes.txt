# Enhancement Shaman — Stormstrike (17364) / Windstrike (115356), 2026-08-26.
# Reported live: a player pressing Windstrike during Ascendance felt it wasn't cooldown-gated at
# all. Traced via raw spelldata + live modifiersFor()/effectiveCooldown() calls against the real
# admin-default Enhancement build:
#   - Ascendance has a real, structurally-linked spell_relationships row to both spells
#     (modifies_cooldown/modifies_charges) — but Ascendance's own raw effect data says its
#     recharge-time modifier is -60%, while its own tooltip prose says "-9%". The two disagree;
#     neither is trustworthy enough to bake into effectiveCooldown() as a computed number.
#   - Elemental Tempo (a real spec talent) reduces Stormstrike's cooldown by a flat amount for
#     EVERY stack of Maelstrom Weapon consumed — described only in prose (no Affected-Spells
#     structural link at all), and Maelstrom Weapon is spent constantly via Tempest/Chain
#     Lightning, exactly the abilities that dominate a real burst window. This is the likely
#     dominant real cause of "feels ungated."
# Both spells share one cooldown/charge pool in-game (Ascendance transforms Stormstrike into
# Windstrike, same underlying ability) even though Elemental Tempo's own text only names
# "Stormstrike" literally — the note is applied to both spell_ids for that reason.
